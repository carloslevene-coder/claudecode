# Goodweek ASCII Edge 2026 Deck

Single-file HTML/CSS/JS presentation deck. Static. No build step.

## Run locally
Serve the directory with any static server, e.g.:
```
python3 -m http.server 8080
```
Then open <http://localhost:8080/>.

## Deploy
Deployed via Vercel as a static site (no framework). The default `index.html` route serves the deck.
